# C++ Practice Programs — Micro IT Internship

A collection of C++ programs built during the **C++ Programming Internship at Micro Information Technology Services**, focused on strengthening core programming, Object-Oriented Programming (OOP), and Data Structures & Algorithms (DSA) fundamentals.

---

## 📂 Programs

| Program | Description |
|---|---|
| **Calculator** | A C++ program implementing basic arithmetic operations |
| **Tic-Tac-Toe** | A console-based Tic-Tac-Toe game demonstrating game logic and control flow in C++ |

---

## 🛠️ Tech Stack

- **Language:** C++
- **Concepts:** OOP fundamentals, control flow, DSA basics

---

## 🚀 Getting Started

### Prerequisites
- A C++ compiler (g++ / MinGW / MSVC)

### Build & Run
```bash
git clone https://github.com/Aaradhyavijay/Portfolio-project-for-MicroIT.git
cd Portfolio-project-for-MicroIT

# Example: running the Calculator program
g++ Calculator/calculator.cpp -o calculator
./calculator

# Example: running the Tic-Tac-Toe program
g++ tictactoe/tictactoe.cpp -o tictactoe
./tictactoe
```
*(Update file paths above to match the actual file names inside each folder)*
